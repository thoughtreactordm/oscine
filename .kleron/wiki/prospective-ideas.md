# Prospective Ideas
### Tools Features
Set of advanced functions and widgets:
 - Bulk operations
 - CD ripping with MusicBrainz autotagging search
 - Parametric EQ with preset saving
   - Assign Genres, Artists, Albums, or Playlists to EQ presets and they will automatically adapt to use their assigned profile
 - Web/hooks
   - Action driven event hooks for users to do something with
   - Eg. song finished playing -> webhook to some IoT light and it changes color (not really Fermata's concern) or interacts with some custom API they use, etc
